# 常见问题

## 没有发现设备

检查线缆或接收器，重新连接后刷新。仅通过蓝牙连接、或未暴露雷蛇 USB HID 标识的
链路不在当前枚举范围。空列表不等于确认硬件不受支持。
RazeRS 不会为了列出描述符而安装内核驱动或要求 root 权限。

## 控制按钮不可用

这是预期行为：当前版本只有描述符枚举。上游的支持声明不等于已实现的 RazeRS 控制。
授予更多权限也不能解锁尚未实现的驱动。

## Agent 启动失败或协议错误

请保持同一发行包中的全部程序在一起，不要混用不同版本。
替换完整程序包后再刷新。展开“技术详情”查看原始诊断；提交问题前请隐藏个人路径。
如果缺少旁边的 Agent，桌面程序会以自己的子进程入口作为开发回退。

## 语言或字体异常

手动选择语言，或用 `--lang zh-CN` / `--lang en` 启动。
“跟随系统”模式下，环境变量可能覆盖系统原生语言。中文字体已内置，无需安装系统语言包。
报告显示问题时请附上语言、缩放比例、操作系统和已脱敏截图。

## 系统信任提示和较旧的 Linux

当前归档不是签名安装器。请验证来源与 SHA-256，不要全局关闭系统安全功能。
若 glibc 不兼容，可在目标系统从源码构建，见[快速开始](getting-started.md)。

请通过 [GitHub Issues](https://github.com/YangYuS8/razers/issues) 反馈。
不要公开序列号、原始输入流、访问令牌或私人诊断信息。
