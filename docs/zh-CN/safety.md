# 硬件安全政策

厂商命令可能导致设备断开、持久设置损坏甚至固件不可用。
安全是架构要求，不能只靠操作前弹出警告。

## 命令风险级别

| 级别 | 含义 | 默认策略 |
| --- | --- | --- |
| `read-only` | 描述符或状态查询 | 仅允许精确匹配、有证据支持的设备 |
| `reversible` | 临时 DPI、灯光等 | 基于已核对证据，实验性显式启用；已验证能力可默认开放 |
| `persistent` | 设备或板载存储写入 | 需要明确确认与验证 |
| `experimental-write` | 尚未完整理解的命令 | 仅开发构建和允许列表 |
| `firmware` | 引导程序或固件操作 | 不属于普通 Agent/IPC |

未知设备只允许安全探测：枚举描述符与经审阅的信息查询，不得持久写入、穷举命令、
对真实硬件模糊测试或操作固件。来源固定、回放覆盖编码与错误路径的上游结果可支持
类型化只读和可撤销实验性操作；无需每个设备都由维护者实测，但 RazeRS 自身的
`verified` 声明仍需要限定平台、固件和连接的记录。

## 原始数据包工具

普通发行版和公开 IPC 不得提供任意数据包写入。研究工具若引入此能力，必须同时具备：
显式开发构建、设备/固件允许列表、速率限制、有界重试、可见风险提示、本地审计日志，
且不自动上传数据包或标识。模糊测试只针对纯编解码器和 CI 回放传输。

## 诊断与隐私

分享前须隐藏序列号、稳定蓝牙标识、主机名、用户名、个人路径、账号或云标识、令牌、
应用密钥、无关 HID 流量与原始输入内容。诊断上传必须由用户主动发起，不得默认采集或传输。

## 当前保证

Agent 可以枚举 HID 描述符，但不会打开设备或写入硬件。设备路径与序列号值不会跨越 IPC。
工作区中唯一的报告 I/O 实现仍是 `ReplayTransport`。
