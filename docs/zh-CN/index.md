# 欢迎使用 RazeRS

RazeRS 是一个本地运行、跨平台的雷蛇外设管理项目。没有广告，无需账号，
默认不采集遥测，也不会在后台上传设备数据。

**当前边界：只读预览。** 应用可以发现 HID 描述符、展示社区证据，但不会打开硬件、
读取设备设置或发送报告。“已知能力”不等于“已经实现的控制功能”，目前尚不能作为
功能完整的官方驱动替代品。

首次使用请阅读[快速开始](getting-started.md)、[桌面应用](application.md)和
[常见问题](troubleshooting.md)。开发者可继续阅读[架构](architecture.md)、
[证据政策](evidence-policy.md)与 [API 参考](api.md)。

本站跟随 `main` 分支持续更新，可能包含尚未发布的功能。
请结合所用版本的[发行说明](https://github.com/YangYuS8/razers/releases)阅读。

RazeRS 是独立社区项目，不隶属于 Razer Inc.，也未获得其背书。
