# Welcome to RazeRS

RazeRS is a local, cross-platform application for Razer peripherals. It has no
advertising, required account, default telemetry, or background device-data upload.

**Current boundary:** this is a read-only preview. It discovers HID descriptors and
shows community evidence, but does not open hardware, read settings, or send reports.
Known capabilities are not implemented controls. Do not replace a working device
configuration tool expecting feature parity yet.

Start with [installation](getting-started.md), [the desktop app](application.md),
or [troubleshooting](troubleshooting.md). Developers can read the
[architecture](architecture.md), [evidence policy](evidence-policy.md), and
[API reference](api.md).

This site follows `main`, so it may describe features newer than the latest release.
Check the [release notes](https://github.com/YangYuS8/razers/releases) for your version.

RazeRS is independent and is not affiliated with or endorsed by Razer Inc.
