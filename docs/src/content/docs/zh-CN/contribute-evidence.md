---
title: 不持有硬件也能贡献证据
description: 将上游实现整理为可审查的贡献，不重复要求硬件测试。
---

没有对应设备，也可以贡献来源链接、设备清单、协议测试或翻译。
实机报告是另一种可选贡献，不是所有贡献的前提。

1. 在源码仓库运行 `cargo run -p razers-cli -- upstream lookup 1532:0099`
   （替换为目标 VID:PID），查看已有来源。
2. 运行 `cargo run -p razers-cli -- upstream assess 1532:0099`，定位具体缺失或有争议的字段。
   名称不同本身不代表事实冲突。
3. 找到上游仓库、确切 commit、路径、符号和许可证。已知时记录连接方式、硬件修订、单位和固件范围，
   不要猜测未知值。
4. 来源不一致时，检查实现与历史，保留双方声明并解释判断依据，不自动选择最新数字。
5. 提交 **Upstream evidence / 上游证据** Issue，或范围集中的 PR。
   附上相关来源链接；贡献协议代码时补充无硬件回放测试。

只有实际测试结果才使用 **Device hardware report / 设备实测报告**。
分别列出成功、失败和未测试的能力，隐藏序列号、私人路径及原始输入。
不要为了填完报告而运行未经审查的写入。

来源记录被接纳不意味着自动启用控制。
实验性支持与特定范围的验证要求见[证据政策](/razers/zh-CN/evidence-policy/)。
