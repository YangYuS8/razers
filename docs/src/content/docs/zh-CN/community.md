RazeRS 是由志愿者维护的小型项目。应用不要求账号；在 GitHub 参与社区使用 GitHub 自己的账号体系。

- [提问或提出功能建议](https://github.com/YangYuS8/razers/issues/new/choose)。
  欢迎文档和翻译反馈，不要求持有硬件。
- [贡献上游证据](/razers/zh-CN/contribute-evidence/)，与实机报告分开提交。
- 报告可复现缺陷时，提供版本、平台、预期结果与复现步骤。
- 漏洞及硬件安全问题请通过 [GitHub 安全报告](https://github.com/YangYuS8/razers/security/advisories/new)**私密提交**。

请遵守[行为准则](https://github.com/YangYuS8/razers/blob/main/CODE_OF_CONDUCT.md)。
尊重讨论中的人，不公开私人标识或未经脱敏的输入数据。
维护者负责范围和发布决策，可以要求证据或收窄提案以保证安全和可维护性，不承诺固定响应时间。

手册跟随开发分支更新；发行说明记录已发布变化。
上游目录条目和成功构建，都不等于 RazeRS 实机验证。
