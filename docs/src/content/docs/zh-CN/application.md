概览按照 USB 产品标识归并 HID 接口，并不代表物理设备数量。
两只同型号鼠标目前可能显示为一个型号。点击“刷新设备”会通过私有 Agent 子进程
重新获取描述符快照，不会读取设备设置。

## 切换语言

在语言菜单中选择**跟随系统**、**English** 或 **简体中文**，无需重启即可切换。
桌面框架会在自动保存或正常退出时将选择保存在本机。`--lang` 命令行参数优先于
已保存的选择，并成为本次选中的偏好。

自动选择依次读取第一个非空值：`RAZERS_LANG`、`LC_ALL`、`LC_MESSAGES`、`LANG`，
然后使用系统原生语言。中文区域变体统一使用简体中文；其他未支持的语言回退到英文。
解析环境偏好时跳过 `auto`。

```bash
razers --lang zh-CN
razers --lang en
RAZERS_LANG=zh-CN razers
```

界面标签、支持说明、能力标签、空状态、错误摘要和悬停提示均支持中英文。
设备型号、标识符、来源符号和原始技术诊断保持原样，避免影响定位与排障。
错误会显示翻译后的摘要，原始内容折叠在“技术详情”内。
较新 Agent 返回的未知文案回退到原文；旧版 v1 Agent 可以继续读取，但缺少用于
翻译来源数量的结构化元数据。

## 隐私和支持状态

字体与设备知识内置在程序中，启动、发现设备和切换语言无需联网。
仅当你主动点击“使用文档”链接时才会打开外部浏览器。没有账号、广告或后台上传。

“已知能力”展示证据，不意味着当前已提供对应控制。“打开控制面板”在本阶段仍禁用。
请先了解[支持级别](/razers/zh-CN/evidence-policy/)，再解读 `detected`、`experimental`、`verified`。
