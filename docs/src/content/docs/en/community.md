---
title: Community and support
description: Choose the right place for questions, feature requests, evidence, translations, and private safety reports.
---

RazeRS is a small, volunteer-maintained project. There is no account requirement in
the application; GitHub participation uses GitHub's own account system.

- [Ask a question or suggest a feature](https://github.com/YangYuS8/razers/issues/new/choose).
  Documentation and translation feedback are welcome; hardware ownership is not required.
- [Contribute source evidence](/razers/contribute-evidence/) separately from hardware reports.
- Report reproducible bugs with version, platform, expected result and reproduction steps.
- Report vulnerabilities and hardware-safety problems **privately** through
  [GitHub security reporting](https://github.com/YangYuS8/razers/security/advisories/new).

Follow the [code of conduct](https://github.com/YangYuS8/razers/blob/main/CODE_OF_CONDUCT.md).
Discuss ideas respectfully; do not publish private identifiers or unredacted input.
The maintainer makes scope and release decisions and may request evidence or narrow
a proposal to keep the project safe and maintainable. Response times are not guaranteed.

The handbook follows the development branch. Release notes describe shipped changes;
neither a source catalog nor a successful build establishes hardware verification.
