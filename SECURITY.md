# Security policy

RazeRS is pre-alpha software and currently has no supported release series.

Please report security issues privately through GitHub's **Report a vulnerability**
feature instead of opening a public issue. Include the affected commit, operating
system, device model, and the minimum reproduction necessary. Remove device serial
numbers, packet payloads containing identifiers, access tokens, and personal paths.

Hardware damage, persistent configuration corruption, privilege-boundary bypasses,
unsafe IPC access, and unintentional disclosure in diagnostic bundles are treated
as security-sensitive issues.
