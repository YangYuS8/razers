# Support / 获取帮助

[English handbook](https://yangyus8.top/razers/) · [中文手册](https://yangyus8.top/razers/zh-CN/)

Start with the handbook's troubleshooting guide. For questions, suggestions,
documentation corrections, bugs, or device evidence, choose the appropriate
[GitHub issue form](https://github.com/YangYuS8/razers/issues/new/choose).
You do not need to own hardware to contribute upstream evidence or translations.
Include only relevant, redacted information. This volunteer project cannot promise
a response time or support for a particular device.

请先阅读手册中的排障说明。提问、建议、文档纠错、缺陷和设备证据请使用对应的
[GitHub 表单](https://github.com/YangYuS8/razers/issues/new/choose)。
贡献上游证据或翻译无需持有硬件。只提供相关且已脱敏的信息；志愿维护项目不承诺响应时间或特定设备支持。

Security vulnerabilities and hardware-safety issues must be reported privately;
see [SECURITY.md](SECURITY.md). Do not post serial numbers, private paths, tokens,
or raw input captures. 漏洞与硬件安全问题请按安全政策私密报告，不公开序列号、私人路径、令牌或原始输入。
