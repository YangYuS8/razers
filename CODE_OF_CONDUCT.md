# RazeRS community code of conduct / 社区行为准则

RazeRS welcomes people of all backgrounds and experience levels. Be respectful,
assume good intent where reasonable, and critique ideas rather than people.
Questions, documentation, translations, upstream research, and code are all useful
contributions; owning a device is not a requirement for participating.

Harassment, discrimination, threats, sexual harassment, deliberate disruption,
and publishing another person's private information are not acceptable. Never
pressure someone into unsafe hardware tests or disclosure of private diagnostics.
These expectations apply in project issues, pull requests, and other official
community spaces, including when representing the project elsewhere.

The repository maintainer, [YangYuS8](https://github.com/YangYuS8), is responsible
for enforcement. Depending on context and severity, responses may include a warning,
removing content, closing a discussion, or restricting participation. Decisions
should be proportionate, explained where possible, and protect affected people's privacy.

Use GitHub's **Report content** facility to report abuse privately to GitHub. For
project moderation, flag the affected public conversation to the maintainer without
repeating private or abusive content. Do not invent a private contact channel;
this project currently has no separate confidential moderation mailbox. Security
reports belong in the [security reporting channel](SECURITY.md), not public issues.

## 简体中文

欢迎不同背景与经验水平的人参与。尊重他人，合理理解善意，讨论观点而不攻击个人。
提问、文档、翻译、上游研究和代码都有价值，不要求持有设备。

禁止骚扰、歧视、威胁、性骚扰、蓄意干扰和公开他人隐私。
不得逼迫别人进行危险硬件测试或公开私人诊断信息。
准则适用于项目 Issue、PR、其他官方社区空间及代表项目的活动。

仓库维护者 [YangYuS8](https://github.com/YangYuS8) 负责执行，根据情境与严重程度可采取提醒、
移除内容、结束讨论或限制参与等措施。处置应适度、尽可能说明理由，并保护当事人隐私。

可使用 GitHub 的 **Report content（举报内容）** 功能向 GitHub 私密举报滥用行为。
需要项目维护者处理公开讨论时，可以在该讨论中提醒维护者，但不要重复传播私人或攻击性内容。
项目目前没有独立的私密社区申诉邮箱，不应捏造联系渠道。
安全问题使用[安全报告渠道](SECURITY.md)，不要公开发帖。
