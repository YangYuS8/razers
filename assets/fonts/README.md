# Bundled Chinese font

`NotoSansSC-Regular.otf` is an unmodified Noto Sans SC Regular font from
`notofonts/noto-cjk` commit `f8d157532fbfaeda587e826d4cd5b21a49186f7c`,
path `Sans/SubsetOTF/SC/NotoSansSC-Regular.otf`.

SHA-256: `faa6c9df652116dde789d351359f3d7e5d2285a2b2a1f04a2d7244df706d5ea9`.

It is embedded as an offline fallback for proportional and monospace text,
including Chinese device names, so system font installation is not required.
The font remains under the SIL Open Font License 1.1 in `OFL.txt`.
The static Regular face avoids variable fonts defaulting to a thin weight in egui.

内置中文字体为未修改的 Noto Sans SC，来源与校验和如上。字体保持 SIL OFL 1.1
许可，不改为项目代码的 GPL 许可。应用完全离线使用，不请求远程字体服务。
